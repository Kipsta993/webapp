# Название: MyApp

# Описание: 
MyApp - это приложение, которое я создаю только для себя одного и только для мобильного устройства. Оно представляет собой To Do List но со всеми моими функциями.

# Технологии:
Html
TypeScript
Css
Sqlite

# Страницы:
№1 - Daily - Задания в определённое время дня(расписание) а так же задания на весь день.
№2 - Weekly - Задания в любое время на всю неделю.
№3 - Stats - Вся статистика про приложение
№4 - Goals - Мои цели
№5 - Diary - Мои заметки
№6 - Settings - Настройки(Этой вкладки нетв нижней навигации, она открывается при свайпе сверху вниз в определённом месте)
